# Runbooks

This directory holds the detailed operational procedures that
`docs/architecture.md` §22 requires; that section gives short numbered
summaries and names this directory as the place the full procedure lives. As
of Phase 0 the only runbook here is `kill-switch.md`, covering how to inspect,
latch, investigate, and clear the Phase-0 file-backed kill switch. Per
`docs/architecture.md` and AGENT.md §8's definition of done ("Runbooks exist
and have been exercised, not just written."), a runbook is not considered done
merely because it has been written down here — it counts as done only once it
has actually been exercised.
